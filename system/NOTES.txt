X server support (Xvfb viewer with keypad pointer/keyboard), Applications launcher for graphical apps, Software store with a 1690-app catalog (Debian AppStream data), apt on /data.

1.5.1: Power saver (Settings > Power saver): modes Off/Light/Standard/Deep. After the screen is off: CPU to lowest speeds, extra cores offline, deep CPU idle allowed; WiFi off after 1 min; Deep suspends with an RTC wake-up timer. Skipped on charger, during calls/ssh/adb. Disabled by default until tested on the phone. Kill switch: /data/jgm/no-powersave. Log: /data/jgm/power.log.

1.5.2: Big package files can live on the SD card (/media/sd/jgmdeb): apt installs are moved there automatically (sd-offload.py, apt post-invoke hook); core system packages are never moved. X window manager start fixed, xterm font.

1.5.3: Menus: the selected row is always fully visible (also the last one) and grows to show its whole text when it is too long; row sizes follow the text size setting.

1.5.4: Call audio: if the modem's voice services are not up yet (call placed soon after the modem started) the voice path is retried until it registers, so the call gets sound.
